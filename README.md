# 在庫・仕入先データ分析ツール

前職（製造業）で Oracle ERP の調達・在庫データを SQL と Excel で手作業分析していた業務を、
Python で自動化することを目的に自主開発したツールです。
調達・在庫データ（CSV）を読み込み、**データクレンジング → 在庫分析 → 仕入先パフォーマンス分析 → レポート自動出力**までを一括で行います。

サンプルデータは、実務で使用していた ERP（調達・在庫・物流モジュール）のテーブル構造を
参考に設計・生成しています。

## 主な機能

| ステップ | 処理内容 |
|---|---|
| 1. データクレンジング | 重複行の削除、仕入先名の空白除去、日付フォーマットの統一（datetime変換）、欠損値（未納品）の除外 |
| 2. 在庫分析 | 在庫金額の算出、カテゴリ別の集計、**安全在庫割れ品目の検出**、ABC分析 |
| 3. 仕入先パフォーマンス評価 | 納期遅延日数の算出、**仕入先別の納期遵守率・平均遅延日数**の集計とランキング |
| 4. レポート自動生成 | 分析結果を Excel（2シート）とグラフ（PNG 2枚）として出力 |

## 出力イメージ

- `output/report.xlsx` … 「在庫分析」「仕入先評価」の2シート
- `output/zaiko_top10.png` … 在庫金額 上位10品目
- `output/supplier_rate.png` … 仕入先別 納期遵守率

## 使用技術

- Python
- pandas（データ処理・集計）
- matplotlib / japanize-matplotlib（グラフ作成・日本語表示）
- openpyxl（Excel出力）

## フォルダ構成

```
.
├── data/                    # サンプルデータ（CSV）
│   ├── zaiko_master.csv     # 在庫マスタ（約100品目）
│   └── nouhin_jisseki.csv   # 納品実績（約600件）

├── src/
│   └── analysis.py          # メインの分析スクリプト

├── requirements.txt
└── README.md
```

## 使い方

```bash
# 依存ライブラリのインストール
pip install -r requirements.txt

# （任意）サンプルデータを作り直す場合
python scripts/generate_data.py

# 分析の実行（output/ にレポートとグラフが生成される）
python src/analysis.py
```

## 開発の背景

前職ではサプライチェーン担当として、月次の在庫レポートや仕入先の納期評価を、
SQL でのデータ抽出と Excel での手作業集計により行っていました。
毎月同じ手順の繰り返しであったため、Python による自動化を学習を兼ねて実装しました。

## 分析結果の例

- **納期遵守率**：海外仕入先の一部で遵守率が低く、平均遅延日数も大きいことが確認できた。
  仕入先の見直しや発注リードタイムの調整といった改善の検討材料になる。
- **在庫金額**：電気部品・機械部品の2カテゴリに在庫金額が集中しており、
  ABC分析でも一部の品目が全体金額の大半を占めることがわかった。

## 工夫した点

- 実務の ERP テーブル構造を参考に、重複行・日付フォーマットの不統一・欠損値・表記ゆれを
  意図的に含んだサンプルデータを生成し、実データに近いクレンジング処理を再現した。
- 集計処理を仕入先分析・在庫分析の関数に分割し、後から分析軸を追加しやすい構成にした。

## 補足

`data/` の CSV は実データではなく、`scripts/generate_data.py` で生成したサンプルデータです。
